# CARBID · Пульт продавца

Программа для Windows: **все кабинеты Wildberries, Ozon и Яндекс Маркета в одном окне**. Заказы FBS, остатки, продажи за 30 дней, вопросы покупателей, расчётная маржа и сторож акций, который исправляет цены и акции только по вашей кнопке.

Здесь выкладывается бесплатная демонстрационная сборка. Демонстрация работает на вымышленных данных — без кода, без ключей API и без оплаты.

## Скачать демонстрацию

**[CARBID-1.2.0-Market-Windows-x64.zip](https://github.com/carbid-soft/pult/releases/download/v1.2.0/CARBID-1.2.0-Market-Windows-x64.zip)** — версия 1.2.0, Windows x64, около 175 МБ.

1. Скачайте и распакуйте архив.
2. Запустите `Install.cmd` или `CARBID.exe` — откроется демонстрация.
3. Свои кабинеты подключаются кодом активации (меню «Активация»).

Проверка целостности архива (PowerShell):

```powershell
Get-FileHash .\CARBID-1.2.0-Market-Windows-x64.zip -Algorithm SHA256
```

Должно получиться: `19d55ba95ddf09a5638c8b1aa96cac8471b06a925dd483eba8314ea9def18d95`

Программа не подписана коммерческим сертификатом, поэтому Windows может показать «Неизвестный издатель». Нажмите «Подробнее» → «Выполнить в любом случае».

## Что делает и чего не делает

- Показывает товары, у которых расчётная маржа после акций и скидок ниже вашего порога.
- Исправляет только по вашей кнопке, после окна подтверждения; каждое исправление пишется в журнал.
- Расчётная маржа — не чистая прибыль. Нет FBO и FBW, рекламы и полных финансовых отчётов; фонового обновления нет.

Подробно, с примерами и скриншотами: **https://carbid-soft.github.io/pult/**
